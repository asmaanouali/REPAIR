# IR-SAM Project-Level Test Manifest
# ===================================
#
# Real, intentionally-vulnerable open-source projects used for end-to-end
# (whole-repository) evaluation. Each record is one line of pipe-separated
# key=value fields consumed by test-phase/run_project_tests.py:
#
#   id        stable identifier
#   url       git clone URL (shallow-cloned, depth=1)
#   ref       branch or tag to check out (default: the repo default branch)
#   lang      primary language (java | python)
#   cwes      comma-separated CWE classes the repo exercises (in IR-SAM scope)
#   labels    ground-truth source:
#               owasp-benchmark  -> expectedresults CSV (real/fake per test)
#               none             -> no machine-readable labels (report only)
#   src       repository-relative path to scan (limits the harness to the
#             vulnerable source tree and skips build/test scaffolding)
#   note      provenance / scope note
#
# Scope: only Java and Python repositories with SQL (CWE-89), OS-command
# (CWE-78), LDAP (CWE-90) and XPath (CWE-643) injection sinks -- the four
# interpreters IR-SAM supports. PHP targets (DVWA, bWAPP) are intentionally
# excluded because IR-SAM has no PHP backend.
