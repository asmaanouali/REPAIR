# IR-SAM Supervisor Report

A long-form narrative report written for the project supervisor, covering motivation, conception, codebase tour, implementation journal, disambiguator narrative, empirical evaluation, Lean tutorial, and reproducibility.

## Build

```powershell
cd paper-supervisor
make
```

Output: `main.pdf`.

## Toolchain

[tectonic](https://tectonic-typesetting.github.io/) is the recommended LaTeX engine because it resolves missing packages on demand without a local TeX Live installation.
